# Texto simples para a página do Guia

## Intenção

Deixar a página `/guias/renda-extra` fácil de entender para visitantes que não conhecem termos editoriais ou de marketing.

## Escopo

Alterar somente a descrição principal, os textos da capa do PDF, a lista de benefícios e a descrição da assinatura mensal. Preços, checkout e estrutura visual permanecem iguais.

## Texto aprovado

- Descrição principal: “Encontre oportunidades de renda extra com mais facilidade. Receba um novo PDF toda semana com ideias, passos simples, links diretos e informações para você escolher por onde começar.”
- Capa: “Renda extra mais simples”, “Ideias de renda extra”, “Passo a passo simples”, “Links diretos para começar”.
- Benefícios: “Um PDF novo toda semana”, “Ideias de renda extra”, “Passo a passo simples”, “Links diretos para começar”.
- Assinatura mensal: “Acesso mensal a novos PDFs com ideias de renda extra, passos simples e links diretos para começar.”

## Critérios

O texto deve usar frases curtas, palavras comuns e explicar claramente o que a pessoa recebe. Não deve prometer ganhos ou resultados garantidos.
