# Mapa Completo de Afiliados — 55 Oportunidades + Ferramentas Complementares

Este documento mapeia todas as **55 oportunidades** ativas no catálogo `/programas`, indicando:
1. Se a plataforma possui **afiliado/indicação direta ativa** ou link oficial direto.
2. Quais **ferramentas complementares monetizáveis (afiliados B2B/SaaS/hardware)** podem ser recomendadas junto a cada card ou página detalhada sem forçar venda.

## Principais Programas de Afiliados Complementares para Cadastrar
1. **Wise (`wise.com/invite`)**: conversão para quem recebe em USD/EUR (Outlier, Micro1, DataAnnotation, Upwork, Amazon KDP).
2. **Payoneer (`payoneer.com/partners`)**: essencial para Walmart Marketplace, Printful e freelancing global.
3. **Amazon Associados (`associados.amazon.com.br`)**: livros, microfones USB, webcams, suportes, livros do KDP.
4. **Mercado Livre & Shopee Afiliados**: iluminação ring light, tripés, suportes de celular para UGC/vídeos.
5. **Canva / OpusClip / HeyGen / ElevenLabs**: ferramentas de edição, cortes virais, narração e criação de capa.
6. **Make (`make.com/en/partners`) / Hostinger / Systeme.io / Notion**: automações, hospedagem, funis e templates.
